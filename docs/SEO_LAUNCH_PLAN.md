# GainingDocx organic search launch plan

The on-site foundation is implemented in the application. The remaining work requires access to search-engine and publisher accounts and should be completed after the updated site is deployed.

## Indexing launch

1. Verify `https://gainingdocx.com` as a Domain property in Google Search Console.
2. Submit `https://gainingdocx.com/sitemap.xml` in Search Console and monitor indexed pages, crawl errors and canonical selection.
3. Inspect the home page, every hub (`/features`, `/tools`, `/templates`, `/guides`) and one representative detail page from each group; request indexing after the deployment is live.
4. Add the site to Bing Webmaster Tools and submit the same sitemap.
5. Validate representative Breadcrumb, FAQ, HowTo, Organization, WebSite and Service JSON-LD with Schema.org Validator and Google Rich Results Test. Structured data improves understanding but does not guarantee a rich result.

## Authority and link earning

- Publish original benchmark studies using anonymized shipping documents: extraction coverage by document type, common ISO 6346 errors, and three-way-match discrepancy patterns.
- Offer the calculators and templates as reference resources to freight-forwarder associations, exporter help centers, logistics training programs and trade-compliance newsletters.
- Create worked examples that demonstrate the calculation and cite the relevant public standard or dataset. Link each example to its calculator and related guide.
- Contribute expert explanations to reputable maritime, customs and supply-chain publications. Ask for a contextual author/source link only where editorially appropriate.
- Maintain accurate product profiles on relevant software directories; avoid bulk directory submissions, purchased links and reciprocal-link schemes.
- Announce genuinely useful new tools, datasets and research through company channels and industry communities without automated spam.

## Measurement

- Track non-branded impressions, indexed canonical URLs, clicks and average position by page group.
- Measure conversions from organic landing pages to tool use, template download and first document upload.
- Review Search Console queries monthly. Improve pages where impressions are growing but the title/description does not earn clicks.
- Refresh `lastModified` in the sitemap only when a page receives a meaningful content or structured-data update.
- Recheck broken links, Core Web Vitals and structured-data validity after every major release.

## Guardrails

- Do not create near-duplicate location or keyword pages.
- Keep FAQs visible on the page and specific to the tool, template or feature.
- Do not promise rankings or indexing. Sitemaps and structured data are discovery and understanding signals, not guarantees.
- Keep private workspace routes `noindex`; only public, useful landing pages belong in the sitemap.
